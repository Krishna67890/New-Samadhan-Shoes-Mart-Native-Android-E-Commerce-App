## ✨ About the Project

**New Samadhan Shoes Mart** is a native Android e-commerce application designed to bring convenient footwear shopping to your fingertips.

Built using Java and Android Studio, the app aims to provide a clean, user-friendly shopping experience where customers can explore footwear collections, discover products, and place orders conveniently through WhatsApp.

🚀 **Coming Soon to Google Play Store!**

The application is currently under development and being prepared for its upcoming release.

## 👟 Explore the Collection

- **Men's Footwear** — Everyday essentials and stylish shoes.
- **Women's Footwear** — Footwear for different styles and occasions.
- **Sneakers** — Modern, casual styles.
- **Formal Shoes** — Footwear for professional occasions.
- **Kids' Footwear** — Styles for younger shoppers.

## 🚀 Key Features

- 📱 **Native Android Experience** — Developed for Android devices.
- 🛍️ **Product Browsing** — Explore the available footwear collection.
- 🖼️ **Product Images** — View footwear through product photography.
- 💬 **WhatsApp Ordering** — Contact the store to place an order.

## ⚙️ Getting Started

### Prerequisites

- Android Studio
- Android SDK
- JDK compatible with the project's Gradle configuration
- Git

### Clone the Repository

```bash
git clone https://github.com/Krishna67890/new-samadhan-shoe-mart-android.git
```

Navigate to the project directory:

```bash
cd new-samadhan-shoe-mart-android
```

### Open and Run

1. Open Android Studio.
2. Select **Open** and choose the cloned project folder.
3. Allow Gradle to sync and download required dependencies.
4. Connect an Android device or start an emulator.
5. Click **Run** to build and launch the application.
